# Ahem 字体说明

[English](../../en/test-fonts/ahem-README.en.md)

Todd Fahrner 开发了 Ahem 字体，帮助作者编写结果可预测的测试。字体的 em 方框是正方形。上升部与下降部的高度之和恰好等于 em 方框的高度，因此字体的垂直范围与行高一致，可以精确地与内边距、边框、外边距等对齐。

字体的字母基线距底部 0.2em、距顶部 0.8em。字体的 x 高度为 0.8em。

字体有四个主要字形：

| 字符 | 码位 | 字形 |
| --- | --- | --- |
| `X` | U+0058 | 高和宽都恰好为 1em 的正方形。 |
| `p` | U+0070 | 高 0.2em、宽 1em 的矩形，顶部与基线对齐。 |
| `É` | U+00C9 | 高 0.8em、宽 1em 的矩形，底部与基线对齐。 |
| 空格 | U+0020 | 高和宽都恰好为 1em 的透明空白。 |

字体中大多数其他 US-ASCII 字符使用与 `X` 相同的字形。

以下 Unicode 格式字符也分配了合适的字形，可以在测试中使用：

- U+2002：半个 em 的空格
- U+2003：一个 em 的空格
- U+2004：三分之一个 em 的空格
- U+2005：四分之一个 em 的空格
- U+2006：六分之一个 em 的空格
- U+2009：窄空格
- U+200A：极窄空格
- U+200B：零宽空格
- U+200C：零宽非连接符
- U+200D：零宽连接符
- U+3000：表意文字空格
- U+FEFF：零宽不换行空格

按上游 `COPYING` 的说明，Ahem 字体属于公有领域。

致谢：

- v2：Paul Nelson 于 2000 年代中期更新字体，在 OS/2 表中加入 x 高度信息，并添加空格和不换行空格字形。
