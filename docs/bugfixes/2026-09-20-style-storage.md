# 样式存储与默认背景分配收敛

## 现象与证据

Issue 107 的列表替换会反复解析和计算样式。调用链显示，属性树逐项分配节点，背景临时向量经过 const 引用复制，每次默认背景计算还创建七个单元素数组。配套 Demo 的既有原生诊断中，100 次实际背景计算的分配从 800 次降至 100 次。

## 修复

属性改为按键排序的连续存储，解析产生的临时向量按所有权移动；背景属性使用已有 get_layer 默认值语义的空向量，保留 image-none 层。变量简写重解析前保存输入，重定位后按键恢复遍历，避免连续存储失效引用。显式属性、继承、important 优先级及背景层数不变。

## 验证与边界

2026-09-20 对本次完整候选源码运行 Release 构建和 CTest，C API 集成回归通过；包含样式级联、背景重置、变量简写刷新和共享背景层用例。验证覆盖最终组合，不宣称每个中间提交独立跑过测试。

既有端到端样本响应 P95 为 51.848 ms，仍未达到 50 ms 门槛，P50 还发生回退。分配减少不能替代端到端验收。背景诊断程序与其 CMake 开关随后续诊断批次提交。

防复发：修改连续存储时检查所有跨写入的属性引用；新增背景默认表示时对照 get_layer，保留显式值、继承和多层差分用例。
