# 动态 DOM 与布局生命周期收敛

## 触发与根因

动态列表反复替换、纯文本更新、flex/grid 重建及节点脱离后继续访问会进入多个失效与布局路径。调用链和差分用例确认：过期 render 弱引用会积累或遮蔽有效放置，flex 容器缺少自身注册，匿名块可能重复初始化；频繁查询与构建还重复分配索引、字体键、解析暂存和列表节点。

## 修复范围

统一渲染引用注册和清理，保留节点身份与失效验证；为 id/tag 查询维护随 DOM 变化失效的弱引用索引；增加属性枚举等 C API 桥接能力。字体缓存使用结构化完整键；解析暂存及布局列表采用复用、转移。只有证明测量尺寸一致且满足限制的数字文本更新才允许保留布局，通用变更仍走完整路径。

文档级布局工作池和隔离文档探针作为诊断保留，LITEHTML_LAYOUT_WORKERS 默认 0。此前所有正工作线程预算的端到端结果均慢于串行，不能据此默认开启并行。

## 验证

2026-09-20 完整候选源码 Release 构建成功，CTest 的 litehtml-layout-api-tests 通过（42 个内部用例）。覆盖节点身份、渲染引用、拆分链接命中、flex/grid 几何、索引变化、文本更新、样式和串并行差分。配套 UE 插件同日 D3D12 自动化 153 项成功，零失败/未运行，最终退出码 0。

这批是源码与既有诊断的归档，不是新的性能达标声明。真实响应尾延迟和高负载脚本中断仍在配套仓库跟踪。防复发检查应继续比较完整重排后的几何、绘制和点击命中，不只比较缓存命中次数。
